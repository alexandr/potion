# Potion

A faithful, open-source recreation of the Notion web app, built with React + TypeScript and running entirely in your browser (no backend — your workspace is stored in `localStorage`).

**Live demo:** https://alexandr.github.io/potion/

## What's inside

- Block editor: text, headings, to-dos, bullets, numbered lists, toggles, toggle headings, quotes, callouts, dividers, code (syntax highlighting), KaTeX equations, images, video, audio, files, bookmarks, embeds, simple tables, columns, table of contents, breadcrumbs, buttons, synced blocks, sub-pages and page links
- Slash menu, markdown shortcuts, inline formatting toolbar, colors, links, @-mentions, `[[` page links, `:` emoji
- Block handles with drag & drop (including into columns and onto sidebar pages), block selection, Turn into, duplicate, move, undo/redo, copy/paste (markdown & HTML)
- Databases: table, board, list, gallery, calendar, timeline and chart views; filters, sorts, grouping, 20 property types incl. formulas, relations and rollups; side/center peek
- Sidebar with favorites, teamspace, private page tree, trash, templates, settings, inbox, search (⌘K), comments, version history, share/publish UI, dark mode, export

## Develop

```bash
npm install
npm run dev
```

Use **Settings → General → Reset demo workspace** to restore the sample content.
